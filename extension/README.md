# Meanwhile

**Meanwhile, you're earning.** A tasteful, single-line sponsor appears in the
"thinking" spinner of Claude Code & Codex while they work — and you earn a 50%
share of the sponsor revenue.

- **Open source & reversible.** Run `Meanwhile: Restore editor` any time to undo
  every change byte-for-byte.
- **Private.** Never reads your code, prompts, or AI responses — it only edits
  the spinner/status display text.
- **Passive.** Earnings accrue while you already work.

## Getting started

1. Install the extension.
2. Click **Meanwhile: Sign in** in the status bar.
3. Use Claude Code or Codex as normal. Earnings begin automatically.

Your balance shows in the status bar: `Meanwhile ($0.42 today · $7.11)`.

## Commands

| Command | Description |
|---|---|
| `Meanwhile: Sign in` | Authenticate and start earning |
| `Meanwhile: Sign out` | Stop earning |
| `Meanwhile: Restore editor` | Undo all patches |
| `Meanwhile: Menu` | Open the full menu |
| `Meanwhile: Diagnose` | Show surface-detection report |

If no compatible surface is found, the extension does nothing — it never breaks
your editor or terminal.
